# 界面风格

当前版本采用黑白浅色界面，顶部可以切换蓝白配色。选择保存在当前应用的本地存储中；两种配色共用同一套布局和组件，只切换交互强调色。

## 设计参考

参考项目的设计方法，未复制其页面代码、品牌资源或截图，也没有引入 React、Tailwind 或组件库依赖：

| 开源项目 | 参考点 | 本项目落地 |
| --- | --- | --- |
| [shadcn/ui Dashboard](https://ui.shadcn.com/blocks?category=dashboard) | 中性色、细边框、工具界面的信息层级 | 浅灰导航、白色内容区、独立指标卡、统一按钮与表单 |

## 统一规则

- 背景使用纯白与中性浅灰，不使用绿色或米黄色铺底。
- 黑白为默认主题；蓝白主题仅对主按钮、选中态和交互链接使用蓝色。
- 成功、警告和错误保留小面积语义色，不作为页面的主色。
- 官方技能图标保持原样；无图或图片加载失败时使用共享的 `SkillIcon`，以淡彩底和 `SkillGlyph` 分类线性图标区分技能。颜色由技能标识稳定计算，优先按名称识别图形，再匹配描述，不联网或写入技能文件。
- 主导航按「工作空间 / 管理」紧凑分组，导航区独立滚动；设置固定在底部。底部本地技能库默认只显示目录简称和技能数量，展开后查看完整路径、打开目录或进入目录设置。
- 技能市场卡片可点开只读详情；腾讯源按需加载官方详情和 SKILL.md，正文以纯文本显示，避免远程 Markdown 中的 HTML 进入应用页面。
- 不重复显示所有健康技能的「OK」标签；异常状态依然可见。
- 页面标题、说明、数字和路径分别使用稳定的字号层级，正文以可读性为先。
- 主题变量集中在 `src/styles/global.css`；配色持久化由 `useAppearance` 管理，业务状态不参与主题控制。
- 不修改 Agent 检测、技能分配或文件部署规则。

## MCP 配置与检测

MCP 编辑器参考用户提供的配置弹窗：左侧字段名、右侧输入区，命令 / HTTP / SSE 分段切换，完整命令一行输入，环境变量键值行及可选择的 Agent。可用性结果与配置放在同一弹窗，保存后默认真实检测；列表保留紧凑状态，点开查看工具和失败原因。凭证默认遮蔽，检测结果使用语义色并显示检测时间。弹窗正文独立滚动，底部操作固定可见。

## 应用图标

`public/app-icon.svg` 是唯一图标源：黑色圆角底与白色立方体。侧栏与网页 favicon 直接使用它；运行 `npm run icons` 可通过项目自带的 Tauri CLI 生成 PNG、Windows ICO 等各尺寸资源。

原生窗口与任务栏使用 Tauri 默认应用图标，EXE 资源使用 `src-tauri/icons/icon.ico`；NSIS 的安装程序和卸载程序也显式配置为该 ICO。修改图标后需重新构建程序及安装包。
