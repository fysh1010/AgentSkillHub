# AgentSkillHub v1.1.1

- **统一技能分配**：技能库整合按技能和按 Agent 视图，支持图标启停、全选、全不选、反选及批量预览，只显示已开启管理的 Agent。
- **外部变更自动刷新**：其他工具或文件管理器修改用户技能、链接和 MCP 配置后，界面自动读取实际状态。
- **实体技能转为链接**：支持将 Agent 自有技能复制入库；同名实体目录经预览后可保留原目录备份并转为技能库链接，也可恢复。
- **工具与路径集中管理**：Skills 和 MCP 路径统一放在设置的 Agent 工具中，通用共享目录单独显示。
- **MCP 分配与市场源**：支持按 Agent 图标和批量分配，增加 Trae / Trae CN 用户级配置适配，以及官方、自定义 Registry 和 HTTP(S) JSON 清单来源。
- 修正「技能库 → 按 Agent」列表中的技能数量：改为统计当前技能库实际启用的技能，与右侧全部开关使用相同数据，不再使用历史分配记录的条目数。
- 计数排除库外自有技能，并随外部链接的删除、恢复自动刷新；悬停数字可查看统计说明。关键词筛选不改变该 Agent 的总启用数。

旧客户端可在「设置 → 通用设置 → 版本更新」点击「检查新版本」，然后下载 `AgentSkillHub-v1.1.1-portable.zip`。关闭旧版程序，解压到新目录后运行 `AgentSkillHub.exe`，沿用现有配置和技能库。Windows 需要 Microsoft Edge WebView2 运行时。

自动检查成功结果缓存 24 小时，手动检查可立即获取最新版本。程序不会自动覆盖正在运行的 EXE；目标 Agent 的授权、信任和连接重载仍需在原工具中确认。
