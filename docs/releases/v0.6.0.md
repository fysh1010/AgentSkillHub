本次更新完善多 Agent 的 Skills / MCP 统一管理，新增 GitHub 技能共享与版本通知。

- 支持指定自己的 GitHub 技能仓库和分支，手动推送、拉取，在多台电脑间共享技能。使用本机 Git 登录，不在客户端保存令牌；远端分叉或存在覆盖风险时停止，不强推。
- 启动检查本项目的正式版本，发现更新时提供发布说明和官方下载按钮；支持关闭自动检查及手动检查。
- 收紧技能发现范围，只枚举明确的用户技能和系统技能目录，停止自动遍历插件缓存、市场和程序安装包，减少无关条目。
- 重新核查常用工具的目录，修正 Cline、Qoder CLI 等路径；支持环境变量和手动添加技能来源。
- 自定义 Agent 可以同时指定 Skills 目录、MCP 配置文件及格式，支持新工具和便携安装位置。
- 完善 MCP 服务库、发现与导入、多 Agent 分配、编辑、暂停、恢复及连接检测；保留原文件备份，检查外部修改，隐藏凭证值。
- MCP 配置确认后立即写入；按 Agent 显示重连或重启提示。目标工具是否热重载由其自身决定，不绕过信任与 OAuth。
- 修复开发版启动附带命令窗口的问题，统一使用 Windows 图形界面模式。
- 更新设置、技能市场详情、图标及主题体验，补充贡献指南和目录核查说明。

下载 `AgentSkillHub-v0.6.0-portable.zip`，解压后双击 `AgentSkillHub.exe`。本版本仅提供 Windows x64 免安装包，需要 Microsoft Edge WebView2 运行时。

配置继续保存在 `%APPDATA%/com.agentskillhub.app`。更新前退出旧程序，再使用新程序；不要覆盖或删除自己的技能库。GitHub 同步仅针对技能库，MCP 凭证、Agent 本机路径和分配设置不随技能上传。

常用目录核查、同步步骤和兼容边界见 [共享与 Agent 管理说明](https://github.com/fysh1010/AgentSkillHub/blob/main/docs/SHARING-AND-AGENTS.md)。本次未对所有 Agent、所有历史版本做实机验证。
