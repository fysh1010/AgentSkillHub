本次更新集中改善本机 Agent 识别、配置控制和界面体验。

- 默认只展示已确认安装的 Agent；未安装产品和配置残留放入单独列表。
- 每个工具新增「允许配置」开关，关闭后从配置和技能分配入口隐藏，后端同步限制操作。关闭不移除原链接或分配记录，重新扫描、重启后保持选择。
- 内置 63 条产品路径规则，结合 PATH、安装登记、运行进程、开始菜单、常见安装位置和 IDE 扩展清单识别；路径跟随当前用户，支持环境变量和自定义工具。
- 本机发现合并到设置，统一浏览 WorkBuddy、豆包等工具的内置技能及插件来源，可查看目录、技能清单并复制到技能库。
- 提供黑白、蓝白两种配色，优化左侧导航与 Agent 选择列表，统一应用、窗口和任务栏图标资源。
- 保护关闭工具的原分配，防止通过清单导入或删除共享技能间接改变配置。

下载 `AgentSkillHub-v0.3.0-portable.zip`，解压后双击 `AgentSkillHub.exe`，无需安装。本版本仅提供 Windows x64 免安装包。

需要 Microsoft Edge WebView2 运行时；Windows 11 通常已具备，Windows 10 如缺少需先安装运行时。配置保存在 `%APPDATA%/com.agentskillhub.app`，技能库与已有配置保留。
