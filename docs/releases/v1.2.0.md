# AgentSkillHub v1.2.0

- **多层文件夹识别**：技能库中的技能可以放在任意层文件夹内，支持“外层/再包一层/分类/技能/SKILL.md”等结构，无固定扫描层数限制。
- **分类浏览与筛选**：列表、卡片和按 Agent 视图共用分类、关键词、标签及收藏筛选；选择父分类时包含所有子分类技能。
- **技能边界与循环处理**：找到技能目录后停止向其内部继续识别，避免把 examples、references 中的示例误算为独立技能；跳过隐藏目录、归档目录、node_modules 和目录链接循环。
- **深层目录自动刷新**：多层文件夹中的技能新增、修改或移出后，界面会刷新实际状态。
- **市场与更新兼容**：按完整技能路径识别已安装技能，新安装可以选择分类，更新保留原分类；下载完成后再替换旧版本，并检查下载期间的外部修改。
- **备份与回收站**：加密快照、Git 技能同步及回收站兼容多层分类路径；回收站保留旧平铺格式的读取与还原支持。
- **分配与恢复保护**：Agent 端仍按技能目录名创建链接，保留外部同名技能；旧分类清单可通过显式路径映射兼容导入，防止跨分类迁移直接回放失效的旧部署路径。

下载 `AgentSkillHub-v1.2.0-portable.zip`，关闭旧版程序后解压到新目录，运行 `AgentSkillHub.exe`。沿用现有配置和技能库，无需迁移目录或重新分配已有技能。Windows 需要 Microsoft Edge WebView2 运行时。

旧客户端可以在“设置 → 通用设置 → 版本更新”手动检查新版本。
