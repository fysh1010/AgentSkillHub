# AgentSkillHub v1.1.0

- **统一技能分配**：技能库整合按技能和按 Agent 视图，支持图标启停、全选、全不选、反选及批量预览。只显示用户已开启的 Agent。
- **外部变更自动刷新**：在文件管理器或其他工具中增改用户技能、技能链接与 MCP 配置后，界面自动重新读取实际状态。
- **实体技能转为链接**：识别其他工具安装的用户技能，支持复制入库；同名实体目录可预览后保留备份并转为技能库链接，也可恢复原目录。
- **工具与路径集中管理**：Skills 和 MCP 路径统一放在设置的 Agent 工具中。`.agents/skills` 独立显示为通用共享目录；Agent 内置技能交由原工具维护。
- **MCP 按 Agent 分配**：支持图标选择和批量分配，移除重复的发现与导入页面。新增 Trae / Trae CN 用户级 MCP 默认路径适配，继续保留预览、外部修改检测与恢复能力。
- **可配置 MCP 市场源**：支持官方及自定义 Registry、HTTP(S) JSON 清单，显示服务图标、发布者头像或占位标识；来源可在界面管理和切换。

下载 `AgentSkillHub-v1.1.0-portable.zip`，解压后双击 `AgentSkillHub.exe`。沿用现有配置和技能库，Windows 需要 Microsoft Edge WebView2 运行时。目标 Agent 的授权、信任及连接重载仍在原工具中确认；市场联网结果取决于来源可用性。
