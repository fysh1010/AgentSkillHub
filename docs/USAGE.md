## 1. 核心概念

### 1.1 技能（Skill）

一个技能就是一个文件夹，里面至少有一个 `SKILL.md`，用 YAML frontmatter 描述自己：

```markdown
---
name: my-skill              # 技能标识（英文 slug）
display_name: 我的技能       # 可选，展示名（通常中文）
version: 1.2.0              # 可选，版本号
description: 这个技能做什么  # 可选，支持 YAML 块标量多行写法
---

这里是技能的正文说明……
```

Claude Code、Codex 等 AI 工具会读取各自 `skills` 目录下的这些文件夹，让 AI 获得对应能力。

### 1.2 唯一技能库 + 逐技能 Junction

AgentSkillHub 的核心设计：

- **技能库**（默认 `E:\my-skills`）是所有技能的唯一真实存放地；
- 给某个 Agent 配置技能 X = 在该 Agent 的 skills 目录创建一个指向技能库的 **Junction 链接**（`mklink /J`，Windows 目录联接，不需要管理员权限）；
- Junction 对程序完全透明：AI 工具读 `skills/xxx` 就等于读技能库里的 `xxx`；
- 因此：**改一处，所有配置了该技能的工具即时生效；删除链接，源文件毫发无损**。

```
技能库 E:\my-skills\gh-cli\          ← 唯一真实源
   ├── SKILL.md
   ├── scripts/
   └── references/
        ▲            ▲            ▲
        │            │            │  Junction 链接
C:\Users\…\.claude\skills\gh-cli
C:\Users\…\.codex\skills\gh-cli
C:\Users\…\.zcode\skills\gh-cli
```

### 1.3 应用内回收站

删除技能 = 把目录移入 `技能库\_archive\trash`（同一块盘上的移动，瞬时完成）：

- **还原**：一键移回原位置；
- **彻底删除**：这时才移入 Windows 系统回收站（还有最后一道保险）；
- 更新市场技能时，旧版本也会先进这里，更新失败可随时回滚。

### 1.4 安全边界

- 不是本工具创建的链接 / 目录（如各工具自带的 `.system`、你手动放的实体技能）**一律不碰**；
- 部署可先「干跑」预览差异，确认后才执行；
- 每次部署写入审计日志，可一键回滚。

## 2. 首次配置

1. 启动应用，进入 **设置** 页；
2. **技能库根目录**：默认 `E:\my-skills`，可改成任意本地路径（建议独立分区/目录，便于 Git 备份）；
3. **Agent 列表**：内置 6 个（Claude Code / OpenAI Codex / Zcode / WorkBuddy / Agents / 豆包），路径不对的直接改；有新工具点「自动检测」一键注册；
4. 完成。技能库目录里已有的技能会被自动扫描出来。

> 技能目录结构：技能直接平铺在根目录（`E:\my-skills\技能名\`）。
> 以下划线 `_` 或点 `.` 开头的目录**不参与扫描**（如 `_archive` 归档、`.git`）。

## 3. 总览页

| 区域 | 说明 |
|---|---|
| 统计卡片 | 技能总数 / 健康技能数 / Agent 数量 / 待部署数 |
| 未分配提醒 | 「有 N 个技能还没分配给任何 Agent」，点击直达 Agent 配置页 |
| Agent 状态卡片 | 每个工具的绿/黄/红灯：就绪 / 待部署（配置与实际链接不一致）/ 异常（目录不存在）；**点击卡片可查看该工具已配置的技能清单**（含链接目标路径、自动翻译的描述） |
| 外部目录 | 卡片上的「外部目录 ⌕」数字：该 Agent skills 目录里**非本工具创建的实体技能**，点开可一键「收编」进技能库（复制过来，原目录不动） |

## 4. 技能库页

### 4.1 浏览与搜索

- 顶部搜索框：按名称 / 描述 / 目录名模糊搜索；
- 分类条：按技能所在目录（平铺模式下都是「全部技能」）+ **★ 收藏**筛选。

### 4.2 卡片

- **图标**：优先显示技能自带 / 市场落盘的官方图标，没有则按内容自动匹配 emoji；
- **名称**：中文展示名优先（frontmatter `display_name`），下面小字是目录名（slug）；
- **状态**：OK = SKILL.md 存在且 frontmatter 合法；
- **悬浮按钮**：右上 ★ 收藏 / 右下 🗑 删除（进应用内回收站）。

### 4.3 详情弹窗

点击卡片打开，包含：描述（英文自动翻译成中文）、路径、大小/修改时间、版本、健康状态、**标签编辑**（回车添加）、**已分配给哪些 Agent**（开关直接改，改完去部署即可）。

### 4.4 查看全文

详情弹窗左下「📄 查看全文」：

- SKILL.md 渲染成排版良好的 Markdown；
- **安全提示区**：列出 `scripts/`、`hooks/`、`bin/` 目录与 `.py/.sh/.ps1/.bat/.cmd/.exe/.dll/.js` 等可执行文件（橙色高亮）——安装来路不明的技能前，先看这里；
- 文件清单：两层目录树，带文件大小。

### 4.5 应用内回收站

页面底部「🗑 应用内回收站」展开：列出所有已删除技能（原名、大小、删除时间），支持**还原**与**彻底删除**。

## 5. Agent 配置页（部署）

1. 左侧选择 Agent 工具（徽标显示已链接技能数）；
2. 右侧按分组列出技能库全部技能，**开关勾选**；
3. 勾选后差异自动计算，顶部显示「新增 x · 移除 y」；
4. 点「部署」→ 弹窗预览每一条动作（创建/移除哪个链接）→「确认部署」；
   - 「刷新差异」= 干跑，只看不动；
5. 出问题点「回滚」恢复上一次部署状态。

**已同步**的含义：Agent 目录里的实际链接与勾选配置完全一致。

> 提示：如果一个 Agent 的 skills 目录本身是「整目录链接」（历史上链到公共目录），
> 应用会识别出来并提供「导入当前链接为配置」——一键把当前可见技能转为逐技能配置，再部署即自动迁移。

## 6. 技能市场页

### 6.1 三个源

| 源 | 说明 |
|---|---|
| 腾讯 SkillHub（官方） | 官方 HTTP 接口，60 条/页精选榜，支持关键词翻页搜索，中英双语描述，带官方图标 |
| ClawHub 社区市场 | 留空浏览热门推荐（下载量 + star 双路各 3 页），关键词精准搜索 |
| GitHub 源 | 任意 GitHub 仓库（如 `anthropics/skills`），设置页/市场页可添加，列出仓库内全部技能目录 |

### 6.2 浏览体验

- 默认进入腾讯源（加载最快）；ClawHub 留空即社区推荐 feed；
- 结果**按分类分组**展示，组内按下载量/star 降序；
- 滚动到底部自动加载下一页（无限滚动）；
- 卡片显示：官方图标/发布者头像、版本、安全扫描状态、下载量、更新日期、来源徽标。

### 6.3 安装

1. 点「安装」→ 下载 → 解压 → 自动**归位到技能库根目录**（腾讯源的 `@命名空间/技能` 嵌套结构会被展平）；
2. 官方图标自动落盘为技能目录的 `_icon.png`（超 3MB 跳过，失败不影响安装）；
3. 成功后弹出「启用到 Agent」对话框：勾选要用的 Agent → 确认 → 自动写配置并部署链接，**装完即用**；
4. 含 `scripts/` 等可执行内容的技能，弹窗顶部有黄色风险提示。

### 6.4 更新

- 已安装技能若市场有新版本，卡片标橙色「**可更新**」徽标，按钮变为「更新到 vX.Y.Z」；
- 更新 = 旧版本先移入应用内回收站 → 下载安装新版本 →（已部署链接的 Agent 无需重新配置，链接名不变自动指向新内容）；
- 版本对比基于语义化版本（`1.2.3`），本地版本取自 SKILL.md 的 `version` / `metadata.version`。

## 7. 部署记录页

- 每次部署的完整动作清单（哪个 Agent、创建/移除了哪些链接、结果如何）；
- 支持按 Agent 查看、清空日志。

## 8. 设置页

- **技能库根目录**：随时可改，改完自动重扫；
- **Agent 管理**：新增 / 编辑路径 / 删除；「自动检测」扫描用户目录下常见工具的 skills 目录（支持识别重定向到其他盘的 Junction）；
- **技能库 Git 备份**：填一句快照说明 →「立即备份快照」（`git add -A + commit`，目录没有 `.git` 时自动 `git init`）。删错/改坏技能后可 `git checkout` 回任意快照。

## 9. 数据都存在哪里

| 数据 | 位置 |
|---|---|
| 技能源文件 | 技能库目录（默认 `E:\my-skills\<技能名>\`） |
| 应用配置（Agent 列表/勾选/审计/收藏标签/市场源） | `%APPDATA%\com.agentskillhub.app\config.json` |
| 翻译缓存 | `%APPDATA%\com.agentskillhub.app\translations.json` |
| 应用内回收站 | `技能库\_archive\trash\` |
| 归档 | `技能库\_archive\`（不参与扫描） |

卸载应用只需删除安装目录 + `%APPDATA%\com.agentskillhub.app`，技能库完全不受影响。

## 10. 故障排查

<details>
<summary><b>部署失败：拒绝访问 / 目录被占用</b></summary>

某个 AI 工具正在运行并占用 skills 目录。关闭对应工具（或其后台进程）后重试。Junction 的创建/删除本身不需要管理员权限。
</details>

<details>
<summary><b>市场安装报「技能库已存在同名技能」</b></summary>

技能库里已有同名目录。到技能库删掉旧的（会进回收站，可还原）再装；或者这就是同一个技能——卡片可能只是缓存了「未安装」状态，重新进市场页会自动纠正。
</details>

<details>
<summary><b>翻译显示原文不变</b></summary>

免费翻译接口（MyMemory）当日额度用尽或网络不通。翻译只影响展示，不影响功能；隔日自动恢复，或点卡片上的「译」重试。
</details>

<details>
<summary><b>图标没显示官方的</b></summary>

打开技能市场页（对应来源），应用会自动为已安装但缺本地图标的技能补图；补图完成后会 toast 提示并自动刷新。
</details>

<details>
<summary><b>ClawHub 空白 / GitHub 源报限流</b></summary>

GitHub 匿名 API 限额 60 次/小时，属正常现象，稍后再试；ClawHub 推荐依赖其 `clawhub.ai` 可达性。
</details>

<details>
<summary><b>AI 工具没有识别到新技能</b></summary>

1. 确认 Agent 配置页显示「已同步」；2. 重启对应 AI 工具（部分工具启动时才扫描技能目录）。
</details>
