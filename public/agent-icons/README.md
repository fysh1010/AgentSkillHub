# Agent 品牌图标

这些品牌标志取自 [yetone/magpie](https://github.com/yetone/magpie/tree/main/internal/gui/assets/icons) 的公开静态资源（2026-11-12）。SVG 多数来自 [Lobe Icons](https://github.com/lobehub/lobe-icons)，保留原始图形，不用字符绘制仿制标志。Magpie 的 MIT 许可见 `LICENSE.magpie`；Lobe Icons 的许可见 `LICENSE.lobe-icons`。品牌名称、商标归各自所有者。

资源随应用离线加载。未收录或自定义的 Agent 使用名称首字占位，不标记为官方图标。

`lingma.png` 为[通义灵码官网](https://lingma.aliyun.com/)公开页面引用的品牌 favicon，原地址：https://img.alicdn.com/imgextra/i1/O1CN01BN6Jtc1lCfJNviV7H_!!6000000004783-2-tps-134-133.png 。

`marvis.png` 为本机 Marvis 1.60.3300.408 安装资源中的 `resources/icons/icon-original.png`，仅作产品身份标识。

`catpaw.png` 为[美团 CatPaw 官方页面](https://catpaw.meituan.com/)引用的 favicon，原地址：https://s3plus.meituan.net/catpaw-external-resources/login/logo.png 。
