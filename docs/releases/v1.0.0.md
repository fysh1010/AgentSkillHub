# AgentSkillHub v1.0.0

- **多设备 Git 同步**：支持自定义 GitHub、GitLab、Gitea 和其他 HTTPS / SSH 仓库。可以读取现有仓库与默认分支；自用私有仓库可选择按 Git 规则同步整个仓库。
- **同步进度与结果**：推送、拉取显示当前步骤和耗时，失败时标出出错步骤。远端已是最新时会明确提示；同步完成后，技能库在后台刷新。
- **加密技能备份**：支持本地文件夹、网盘同步文件夹和 HTTPS WebDAV。恢复到独立目录，可预览后再切换技能库。
- **版本更新**：启动或手动检查正式 Release，发现新版后可确认下载并运行 Windows 便携版。

下载 `AgentSkillHub-v1.0.0-portable.zip`，解压后双击 `AgentSkillHub.exe`。沿用现有配置和技能库。Windows 需要 Microsoft Edge WebView2 运行时。
